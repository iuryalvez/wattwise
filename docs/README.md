# WattWise documentation

Start with the [project README](../README.md) for a quick introduction and a local run. The interface is currently in Brazilian Portuguese; contributor documentation uses English, and issues and PRs may use either language.

## Use the application

- [Usage guide](USAGE.md): installation, Ollama, command-line modes, evidence labels, and limitations.
- [Family example](FAMILY_USE_CASE.md): the fictional three-person household and its assumptions.
- [High-consumption example](HIGH_CONSUMPTION_USE_CASE.md): the fictional five-person household.
- [Industrial example](INDUSTRIAL_USE_CASE.md): packaging operations, protected loads, and calendar-day equivalents.
- [Monitoring demonstration](MONITORING_DEMO.md): simulated sensors, connection state, and session energy.
- [ANEEL BDGD data](BDGD_DATA.md): optional medium-voltage consumption analysis, separate from the planning app.
- [Support](../SUPPORT.md): troubleshooting, questions, and bug reports.

## Develop and contribute

- [Contribution guide](../CONTRIBUTING.md): setup, checks, conventions, and review.
- [API errors and recovery](API_ERRORS.md): diagnostic codes, field validation, original backups, and storage failures.
- [Architecture](ARCHITECTURE.md): where the code lives and how data flows.
- [Roadmap](ROADMAP.md): product priorities and scoped contribution ideas.
- [Maintainer guide](MAINTAINING.md): triage, repository settings, and release preparation.
- [Evaluation guide](EVALUATION.md): offline checks, browser verification, and local-model reports.
- [Security policy](../SECURITY.md) and [code of conduct](../CODE_OF_CONDUCT.md).
